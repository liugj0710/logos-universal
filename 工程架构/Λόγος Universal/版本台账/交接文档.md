## 三、已完成修复（新 Kimi 不要重复做）

### 3.1 ingest.py KeyError: 'hash'
- **根因**: `meta` 变量被 Chroma metadata 字典覆盖
- **修复**: 将 Chroma metadata 变量改名为 `doc_meta`，并过滤 None 值（Chroma metadata 不支持 None）
- **状态**: 已修复，165 chunks 入库成功

### 3.2 Chroma 检索链路
- **根因**: ChromaDB `query()` 调用 `embed_query` 方法，与 `__call__` 参数不匹配；Ollama `/api/embeddings + input` 返回空数组
- **修复**: `search_chroma.py` 中手动生成 embedding 传入 `query_embeddings`，绕过 ChromaDB 自动 embedding 调用链
- **状态**: 已修复，查询返回正常结果（score 0.56-0.74）

## 五、关键设计决策（防止幻觉）

1. **Bing 和百度都必须用 DrissionPage，不能用 requests**
2. **Bing 和百度拆分为独立文件**（search_bing.py / search_baidu.py），优化时只改对应文件
3. **内容过滤阈值 200 字是核心防线**，不能降低
4. **模型名统一为 deepseek-v4-flash**
5. **浏览器单例 + 健康检查**，循环导入已修复（fetch_page 函数级导入）
6. **Chroma 是 Deep Lane 私有知识库主力**，Dify KB 留给 Fast Lane
7. **Embedding 用 Mac Studio Ollama bge-m3**，Tailscale 内网调用
8. `.env` 中 `OLLAMA_EMBED_MODEL=bge-m3`（无 `:latest`），Ollama 实际模型名为 `bge-m3:latest`，但 `/api/embed` API 用 `bge-m3` 也能正常调用
